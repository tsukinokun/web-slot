# 沖スロ 企画書（たたき台）

## 決まったこと

- パソコン1台＝お店1軒、台は1台。銀行サーバー（arcade-bank）からお金を出し入れする
- 設定変更はなし。スペックは1つに固定する
- **機械割 94%**（お店が長い目で見て儲かる）
- お客さんに見せるのは**当たりの確率と継続率だけ**。機械割は書かない
- そのぶん演出を派手にして楽しんでもらう
- 実在の機種の再現はしない。図柄・名前・演出はオリジナルにする

## スペック案（数値は `node tools/sim.mjs` で確認）

| 項目 | 値 | お客さんに公開する |
|---|---|---|
| 1回転 | 3枚ベット（1枚=10G 仮） | ○ |
| BIG | 1/297、21G（純増 約210枚） | ○ 確率 |
| REG | 1/455、8G（純増 約80枚） | ○ 確率 |
| ボーナス合算 | 1/179.7 | ○ |
| 継続率 | 20%（ボーナス終了ごとに抽選） | ○ |
| リプレイ・ブドウ・チェリー | 1/7.3・1/6.4・1/36 | ×（非公開） |
| 機械割 | 94.0% | ×（非公開） |

- 1回転ごとに銀行へベット・払い出しを精算する（銀行のベット上限は100G）
- 抽選と払い出しはサーバー側で行う

## わかったこと（シミュレーション結果）

機械割94%でも、短い時間ではお店が負けることがよくある。

| 回転数 | お店が赤字で終わる確率 | お店の最悪5% |
|---|---|---|
| 300 | 約35% | -4,400G |
| 1,000 | 約33% | -7,100G |
| 3,000 | 約25% | -9,400G |

→ 「必ず儲かる」にするには別の仕組みが必要（下の検討事項）。

## 検討事項

1. 打ち止め（お店の負けが一定額に達したら台を止める）を入れるか
2. 1枚あたりの金額（10Gか5Gか）
3. 授業で回る回転数の見込み
4. 演出の内容（先告知・後告知・次ゲーム告知・プレミア・継続演出）
5. テーマ・名前・図柄
