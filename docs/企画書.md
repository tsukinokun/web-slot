# 沖スロ 企画書（たたき台）

## 決まったこと

- パソコン1台＝お店1軒、台は1台。銀行サーバー（arcade-bank）からお金を出し入れする
- 設定変更はなし。スペックは1つに固定する
- **機械割 94%**（お店が長い目で見て儲かる）
- お客さんに見せるのは**当たりの確率と継続率だけ**。機械割は書かない
- そのぶん演出を派手にして楽しんでもらう
- 実在の機種の再現はしない。図柄・名前・演出はオリジナルにする

## スペック案（数値は `node tools/sim.mjs` で確認）

| 項目 | 値 | お客さんに公開する |
|---|---|---|
| 1回転 | 3枚ベット（1枚=10G 仮） | ○ |
| BIG | 1/297、21G（純増 約210枚） | ○ 確率 |
| REG | 1/455、8G（純増 約80枚） | ○ 確率 |
| ボーナス合算 | 1/179.7 | ○ |
| 継続率 | 20%（ボーナス終了ごとに抽選） | ○ |
| リプレイ・ブドウ・チェリー | 1/7.3・1/6.4・1/36 | ×（非公開） |
| 機械割 | 94.0% | ×（非公開） |

- 1回転ごとに銀行へベット・払い出しを精算する（銀行のベット上限は100G）
- 抽選と払い出しはサーバー側で行う

## わかったこと（シミュレーション結果）

授業は3時間で、約2,100回転の見込み。機械割94%で1日を回したとき：

| 1枚 | 打ち止め | お店の平均収支 | 赤字で終わる確率 | 下位5% | 台が止まる確率 |
|---|---|---|---|---|---|
| 10G | なし | +3,900G | 29% | -8,900G | - |
| 10G | -3000Gで停止 | +2,600G | 48% | -5,200G | 46% |
| 5G | なし | +2,000G | 28% | -4,400G | - |
| 5G | -3000Gで停止 | +1,700G | 34% | -3,800G | 24% |

- 機械割94%だと、2,100回転でも約3回に1回はお店が赤字で終わる
- 打ち止めは逆効果。負けているときに止めると取り返す機会がなくなり、赤字の確率が上がる。台も止まりやすい
- 1枚の金額を下げると、ぶれの金額が小さくなる（赤字になる確率は変わらない）

## 検討事項

1. 機械割94%で運のぶれを受け入れるか、機械割を下げて確実性を取るか
2. 1枚あたりの金額（5G案が有力）
3. 演出の内容（先告知・後告知・次ゲーム告知・プレミア・継続演出）
4. テーマ・名前・図柄
