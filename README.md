# てぃだパラダイス（沖スロ）

南国の「てぃだ（太陽）ランプ」が光ればボーナス確定の、ランプ告知型スロットです。
クラスの銀行サーバー（arcade-bank）とつないで遊びます。パソコン1台が1軒のお店です。

## 起動

```bash
npm install
cp .env.example .env
```

`.env` の `BANK_URL` を銀行のURLに、`GAME_KEY` を先生から配られた自分のキーにします。

```bash
npm start
```

`http://localhost:3001` を開きます。お客さんは同じLANから `http://（このPCのIP）:3001` で入れます。

## 遊び方

- 1枚の値段を10〜33Gから選ぶ（1回転は3枚＝30〜99G）
- 「回す！」ボタン（またはスペースキー）を押すと、リールが自動で止まる
- てぃだランプが光ったらボーナス確定。次のゲームでボーナスが始まります
- ボーナスの最終ゲームで継続チャレンジ

## お客さんに公開している数値

| 項目 | 値 |
|---|---|
| BIG | 1/297（21G） |
| REG | 1/455（8G） |
| ボーナス合算 | 1/179.7 |
| 継続率 | 20% |

小役の確率と機械割（約86%）は公開しません。`src/spec.js` にあります。

## ファイル

| ファイル | 役割 |
|---|---|
| `src/spec.js` | 台のスペック（確率・払い出し） |
| `src/engine.js` | 抽選・出目・告知の決定（サーバーだけで動く） |
| `server.js` | ログイン、1回転ごとの銀行とのやりとり |
| `src/store.js` | プレイヤーごとの台の状態を `data/state.json` に保存 |
| `public/` | 画面・リール・演出・音 |
| `node_modules/@fontsource/` | フォント（Dela Gothic One・Zen Maru Gothic・DotGothic16・Yomogi）。サーバーが `/fonts` で配信するので、ネットにつながらない教室でも表示できる |
| `tools/sim.mjs` | 機械割シミュレーター（`npm run sim`） |

`src/spec.js` を変えたら、必ず `npm run sim` で機械割を確認してください。

## しくみ

- 1回転ごとに銀行へベット（3枚×1枚の値段）し、止まった結果の払い出しをすぐ送ります。
- 抽選はすべてサーバーが行います。ブラウザは結果を見せるだけです。
- ボーナスが当たってから連チャンが終わるまでは、1枚の値段が固定されます（安く回して当たったら値段を上げる、ができないように）。
- 台の状態（ボーナス中・残りゲーム数・データカウンター）は `data/state.json` に保存されるので、サーバーを再起動したり退店したりしてもボーナスは消えません。
- ベットの送信がタイムアウトしたときは、次の回転で同じリクエストIDで送り直します。払い出しが届かなかったときも、次の回転で送り直します。

## 店長用

お店のPCで `http://localhost:3001/api/shop` を開くと、台全体の回転数・BIG/REG回数・売上・払い出し・利益が見られます（ほかのPCからは見られません）。

## 注意

- `GAME_KEY` と `.env` は Git に入れないでください。
- 銀行との通信がLANのHTTPの場合は暗号化されません。信頼できるネットワークで使ってください。
